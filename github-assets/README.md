# 新版全屏配图

这些图片由 `node scripts/capture-screenshots.mjs` 从实际 `1.6.2-zh.1` Windows exe 的最大化窗口截取，尺寸均为 1920×1032（1920×1080 屏幕，Windows 任务栏不在应用截图中）。没有缩放旧版小窗口图片。

截图日期：2026-11-05。全部使用独立生成的演示引擎/项目目录，未使用真实账号或私人项目。

- `projects-all-fullscreen.png`：全部版本分组与项目计数。
- `projects-version-fullscreen.png`：选定 UE 5.7 的项目。
- `projects-list-fullscreen.png`：按版本分组的列表视图。
- `engines-fullscreen.png`：源码版/安装版分类与数字版本排序。
- `settings-fullscreen.png`：中文设置、版本号和搜索路径说明。
- `marketplace-fullscreen.png`：商城未登录入口，演示灰屏修复后的正常页面。

演示目录仅供截图，不包含可启动的完整 UE 引擎或项目内容。原仓库旧图片已从当前分支移除，原始历史仍保留在 Git 中。
